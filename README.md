# Daily Work 웹 프로그램 (Python 2.7 버전)

`daily_work`(Python 3 버전)와 기능이 똑같은 프로그램을 **Python 2.7 + Anaconda** 회사 PC에서
돌아가도록 다시 만든 것입니다. 추가 설치는 필요 없습니다 (flask, openpyxl, sqlite3 만 사용).

다음 버전 조합에서 모든 화면과 버튼이 동작하는 것을 확인했습니다.

| 조합 | Python | Flask | Jinja2 | Werkzeug | openpyxl |
|---|---|---|---|---|---|
| 오래된 쪽 | 2.7.18 | 0.10.1 | 2.7.3 | 0.9.6 | 2.2.6 |
| 최신 쪽 | 2.7.18 | 1.1.2 | 2.11.3 | 1.0.1 | 2.6.4 |

## 1. 파일 구조

```
daily_work_py27/
├─ app.py            ← 메인 파일. 웹페이지 주소(route)와 버튼 동작이 모두 여기 있음
├─ db.py             ← 데이터베이스(SQLite) 테이블 구조와 조회 함수
├─ excel.py          ← 엑셀 파일 만들기
├─ backup.py         ← 매일 자동 백업, 오래된 백업 삭제
├─ compat.py         ← ★ Python 2.7 에서 한글을 안전하게 다루는 도우미 (3 버전에는 없음)
├─ check_env.py      ← ★ 회사 PC에 필요한 모듈이 있는지 확인
├─ run.bat           ← 더블클릭 실행 파일 (파이썬 경로 설정 포함). 검은 창이 뜸
├─ start_hidden.vbs  ← ★ 검은 창 없이 백그라운드로 실행
├─ stop_server.bat   ← ★ 백그라운드로 실행 중인 서버 끄기
├─ server.log        ← (백그라운드 실행 시 자동 생성) 서버 메시지 기록. 직전 것은 server_old.log
├─ static/           ← 화면 디자인(style.css), 표 정렬(sort.js)
├─ templates/        ← 화면(HTML). 파일 하나 = 화면 하나
├─ worklog.db        ← (처음 실행하면 자동 생성) 모든 데이터가 저장되는 파일
└─ backup/           ← (자동 생성) 기본 백업 폴더
```

## 2. 회사 PC에 설치하기

1. 이 폴더를 통째로 USB 등으로 복사합니다.
2. ⚠️ **폴더 경로에 한글이 없어야 합니다.** 예: `C:\daily_work_py27` (권장)
   - `C:\Users\홍길동\바탕 화면\업무일지` 같은 곳에 두면 Python 2.7 이 프로그램 파일을 못 읽습니다.
   - (백업 폴더는 한글 경로여도 괜찮습니다.)
3. **Anaconda Prompt**를 열고 폴더로 이동해서 환경을 확인합니다.
   ```
   cd C:\daily_work_py27
   python check_env.py
   ```
   모두 `OK` 가 나오면 됩니다. `MISSING` 이 있으면 화면 내용을 복사해서 알려주세요.

## 3. 실행 방법

실행 방법은 두 가지입니다. **처음에는 1번(run.bat)으로 잘 되는지 확인한 뒤** 2번으로 바꾸는 것을 권장합니다.
(1번은 에러가 바로 검은 창에 보여서 문제를 찾기 쉽습니다.)

### 3-1. 검은 창 띄워서 실행 (run.bat)

1. `run.bat`을 더블클릭합니다.
2. 브라우저에서 http://localhost:5000 에 접속합니다.
3. **계정 만들기**에서 첫 계정을 만들고 로그인합니다.
4. 끄려면 검은 창에서 `Ctrl+C`를 누르거나 창을 닫습니다.

### 3-2. 창 없이 백그라운드로 실행 (start_hidden.vbs)

1. `start_hidden.vbs`를 더블클릭합니다. 아무 창도 뜨지 않지만 서버는 켜져 있습니다.
2. 브라우저에서 http://localhost:5000 에 접속해서 화면이 나오면 성공입니다.
3. 끄려면 `stop_server.bat`을 더블클릭합니다. (`Server stopped.` 가 나오면 꺼진 것)
   - 5000번 포트를 쓰는 프로그램(= 이 서버)만 끕니다. 다른 파이썬 프로그램은 건드리지 않습니다.
4. 검은 창에 나오던 메시지는 프로그램 폴더의 `server.log` 에 기록됩니다.
   접속이 안 되면 이 파일을 메모장으로 열어 보세요. (켤 때마다 새로 쓰고, 직전 기록은 `server_old.log` 로 남김)
   - 서버를 오래 켜 둬도 `server.log` 가 5MB 를 넘으면 `server_old.log` 로 바꾸고 새로 쓰기 때문에 파일이 끝없이 커지지 않습니다.
   - `server.log` 가 아예 없거나 비어 있으면 `server_boot.log` 를 열어 보세요. (프로그램이 시작되기 전에 난 에러가 여기 남습니다. 평소에는 비어 있음)
5. 이미 켜져 있는데 또 실행하면 아무 일도 하지 않습니다. (`run.bat`은 "already running" 안내가 뜸)

> 프로그램 설정(`run.bat`의 파이썬 경로 등)을 바꾼 뒤에는 `stop_server.bat` → `start_hidden.vbs` 순서로 다시 켜세요.

### 파이썬을 못 찾을 때 (run.bat 의 파이썬 경로 설정)

`run.bat`은 자주 쓰는 Anaconda 설치 위치(`C:\Anaconda2`, `C:\ProgramData\Anaconda2`, 사용자 폴더 등)를
자동으로 찾습니다. 검은 창에 `'python' is not recognized` 가 나오거나 버전이 3.x 로 나오면:

1. Anaconda Prompt 에서 `where python` 을 실행해 python.exe 경로를 확인합니다.
2. `run.bat`을 메모장으로 열고 아래 줄에 경로를 넣고 저장합니다.
   ```
   set "MY_PYTHON=C:\Anaconda2\python.exe"
   ```

## 4. 다른 PC에서 접속하기

- 주소: `http://내PC의IP:5000` (예: `http://192.168.0.10:5000`)
- 내 IP 확인: 명령 프롬프트에서 `ipconfig`를 실행하고 "IPv4 Address"를 봅니다.
- **방화벽**: 처음 실행하면 "Windows Defender Firewall" 창이 뜹니다. **Private(개인)와 Domain(도메인) 네트워크 모두 체크**하고 "Allow access"를 누르세요.
  - 창을 놓쳤다면 제어판 → Windows Defender Firewall → Allow an app → **Anaconda 폴더의 python.exe**를 허용합니다.

## 5. 재부팅해도 자동 실행되게 하기

1. `Win + R`을 누르고 `shell:startup`을 입력한 뒤 Enter를 누릅니다. 시작프로그램 폴더가 열립니다.
2. `start_hidden.vbs`를 **마우스 오른쪽 버튼 → 바로 가기 만들기**로 바로 가기를 만든 뒤, 그 바로 가기를 이 폴더로 옮깁니다.
   - 검은 창을 띄워 두고 싶으면 `run.bat`의 바로 가기를 대신 넣으면 됩니다. (둘 중 하나만!)
3. 윈도우에 로그인하면 자동으로 서버가 켜집니다.
4. 절전 모드에 들어가면 접속이 끊깁니다. 설정 → 시스템 → 전원에서 절전을 "안 함"으로 바꿔 두세요.

## 6. 백업과 복원

- 프로그램이 켜져 있으면 매일 1회 `worklog_날짜.db` 파일을 만들고, 보관 기간이 지난 파일은 지웁니다.
- 백업 폴더와 보관 기간은 웹의 **설정** 화면에서 바꿉니다.
- **복원 방법**
  1. 프로그램을 끕니다.
  2. 원하는 백업 파일을 프로그램 폴더로 복사합니다.
  3. 복사한 파일의 이름을 `worklog.db`로 바꿔 기존 파일을 덮어씁니다.
  4. 프로그램을 다시 켭니다.

## 6-1. 화면 사용 안내 (추가된 기능)

- **5팀 분석현황**: 처음에는 **내가 담당자인 분석**만 보입니다. (5팀이 아닌 사람은 전체)
  [전체] 버튼이나 [사람 선택]으로 다른 사람 것을 볼 수 있고, 괄호 안 숫자는 그 날짜의 분석중 + 분석종료 건수입니다.
  - 표가 길어지면 표 안에서 스크롤됩니다. 메인 업무일지, 엑셀, 인쇄는 전체를 그대로 보여줍니다.
  - 분석중이 **90일**을 넘으면 경과일이 빨간색으로 표시됩니다. 끝난 건이면 [분석종료]를 눌러 주세요.
- **검색**: 결과를 한 페이지에 50건씩 보여주고 아래에 페이지 번호가 나옵니다. (50/100/200건 선택 가능)
  - 표 머리글을 누르면 **전체 결과**가 그 열 기준으로 정렬됩니다. 엑셀/인쇄도 같은 순서로 전체가 나옵니다.
  - 결과가 2,000건이 넘으면 인쇄 전에 확인창이 뜹니다. (인쇄 화면이 느릴 수 있어서 엑셀을 권장)
- **전출/퇴직**: 계정을 삭제하지 말고 계정관리 → [수정] → **전출/퇴직일**을 넣으세요.
  그날부터 로그인, 작성자 선택 목록, 미제출 인원에서 빠지고, 그 사람이 쓴 기록은 그대로 남습니다.
  그 전 날짜의 업무일지에는 여전히 미제출 인원으로 나옵니다. 날짜를 다시 비우면 원래대로 돌아옵니다.
- 예전 버전에서 쓰던 `worklog.db` 는 프로그램을 켜면 자동으로 새 구조로 바뀝니다. (데이터는 그대로)
  예전 분석 건의 담당자는 '급수 이름'이 같은 계정에 자동으로 연결됩니다.

## 7. 오류가 날 때

- 검은 창에 나온 오류 메시지 **전체**를 복사해서 알려주세요. (검은 창에서 마우스 오른쪽 → Mark/Select All → Enter 로 복사)
- 백그라운드로 실행 중이었다면 `server.log` 파일 내용을 복사해서 알려주세요.
- 검은 창의 안내 문구는 일부러 영어로 해 두었습니다. 영문 윈도우 검은 창은 한글을 `?` 로 보여줄 수 있는데,
  웹 화면과 데이터에는 아무 문제 없습니다.

## 8. 공부용: Python 3 버전과 다른 점

코드에서 `[Py2.7 차이]` 로 검색하면 모두 찾을 수 있습니다. 주요 내용은 다음과 같습니다.

| Python 3 버전 | Python 2.7 버전 | 이유 |
|---|---|---|
| (없음) | `from __future__ import unicode_literals` | 2.7 은 `'한글'` 이 바이트라서 깨짐. 이 줄이 있으면 unicode 가 됨 |
| `f'{name}님'` | `'{}님'.format(name)` | f-string 은 3.6 부터 |
| `str(값)` | `to_text(값)` (compat.py) | 2.7 에서 `str(u'한글')` 은 에러 |
| `sqlite3.Row` | `dict_row` (db.py) | 2.7 의 Row 는 unicode 이름으로 못 꺼냄 |
| `src.backup(dst)` | 잠금 후 파일 복사 (backup.py) | sqlite3 backup 기능은 3.7 부터 |
| `os.makedirs(..., exist_ok=True)` | `ensure_dir()` (compat.py) | exist_ok 는 3.2 부터 |
| `Thread(..., daemon=True)` | `t.daemon = True` | daemon 인자는 3.3 부터 |
| `send_file(..., download_name=)` | `xlsx_response()` (app.py) | 옛 Flask 는 한글 파일명 다운로드 불가 |
| `request.full_path` | `here` (app.py) | 옛 Flask 에 없음 |
| 템플릿 `namespace()`, `map()` | app.py 에서 미리 계산 | 옛 Jinja2 에 없음 |
| `1500 / 1024` → 1.46 | `1500 / 1024.0` | 2.7 에서 정수끼리 나누면 소수점 버림 |
| (없음) | `import _strptime` (compat.py) | 2.7 은 여러 스레드에서 날짜 변환을 처음 쓸 때 에러가 나는 버그가 있음 |
